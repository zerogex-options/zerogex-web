# Parrainage

*Comment fonctionne le programme de parrainage - votre code, votre lien, ce qui compte comme parrainage et comment les mois gagnés s'appliquent à votre facture.*

---

## En quoi consiste le programme de parrainage

Lorsque le programme de parrainage est en cours, vous obtenez :

- Un **code de parrainage** - un code de 8 caractères qui vous est propre.
- Un **lien de parrainage** - la version facile à partager de votre code (le code est la partie après `ref=`).

Toute personne qui s'inscrit via votre lien puis souscrit une formule payante compte comme un parrainage réussi. Chaque parrainage réussi vous rapporte un mois gratuit, appliqué sous forme de crédit sur votre prochaine facture.

## Où trouver votre lien

Ouvrez [Account](/account). La section **Parrainer un ami** affiche votre lien, avec un bouton **Copier le lien**, et votre situation actuelle :

- **Inscrits** - combien de comptes se sont inscrits via votre lien.
- **Abonnés** - combien d'entre eux ont souscrit Basic ou Pro.
- **Mois gratuits gagnés** - un par filleul qui s'est abonné.
- **Mois accumulés** - des mois gratuits en attente de votre abonnement ; ils sont appliqués automatiquement comme crédit de compte lorsque vous vous abonnez (affiché uniquement si vous en avez).
- **Crédit sur votre prochaine facture** - le crédit de compte qui sera appliqué à votre prochaine facture, le cas échéant.

## Ce qui compte comme un parrainage réussi

- Le nouvel utilisateur doit s'inscrire via votre lien. Il n'existe pas de champ pour saisir un code à l'inscription - c'est le lien qui enregistre le parrainage, et il reste mémorisé 30 jours dans son navigateur : il peut donc d'abord découvrir le site et s'inscrire plus tard.
- Il doit passer à un abonnement payant actif (pour Basic mensuel, cela signifie que l'essai gratuit se termine et se convertit).
- Les auto-parrainages ne sont pas autorisés (détectés automatiquement par le système).
- Vous n'avez pas besoin d'une formule active vous-même. Si vous n'êtes pas abonné lorsqu'un filleul se convertit, le mois gratuit est mis de côté jusqu'à votre abonnement.

## Comment le crédit est appliqué

Chaque mois gratuit est ajouté à votre solde Stripe sous forme de crédit valant un mois de votre formule (pour une formule annuelle, un douzième du prix annuel), et Stripe l'applique automatiquement à votre prochaine facture. Les crédits se cumulent - deux parrainages au cours du même cycle représentent deux mois de crédit.

Les crédits ne sont ni transférables ni remboursables en espèces. Ils expirent si votre compte est fermé.

## Partager votre lien

Deux pratiques que nous observons :

- **Lien direct** - le plus simple. Cliquez sur **Copier le lien** sur la page Account et collez-le où vous voulez.
- **Message privé au bon moment** - quand quelqu'un dans une communauté de trading pose une question sur le gamma exposure, le lien de parrainage est aussi une réponse.

## Ce que le nouvel utilisateur y gagne

Le nouvel utilisateur bénéficie des mêmes conditions standard que tout le monde - l'essai gratuit de 7 jours sur Basic mensuel, ou la garantie satisfait ou remboursé de 7 jours sur toutes les autres formules (aucune extension via votre code), et toute promotion active sur l'ensemble du site s'applique en plus. En plus, sa première facture comprend un bonus de parrainage : **un mois gratuit** en formule mensuelle ou trimestrielle, ou **10% de réduction sur la première année** en formule annuelle. Il ne s'applique qu'au premier abonnement. Vous recevez votre crédit séparément, comme décrit plus haut.

## Confidentialité

La page Account vous montre les adresses e-mail des personnes qui se sont inscrites et abonnées via votre lien - survolez le nombre **Inscrits** ou **Abonnés** pour les voir. Rien d'autre sur leurs comptes ne vous est communiqué.

## Éligibilité et statut du programme

Le programme est activé ou désactivé pour l'ensemble du site. Si vous ne voyez pas de section « Parrainer un ami » sur votre page Account, le programme n'est pas en cours actuellement.
